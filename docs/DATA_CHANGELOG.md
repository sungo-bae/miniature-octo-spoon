## 매일 바뀌지 않지만 알아 둘 것

- **"마감"의 뜻**: 출처 목록에서 사라진 날입니다. 실제 채용 완료인지 기간 만료인지 출처가 알려 주지 않습니다.
- **공고 수정**: 같은 공고 번호의 제목·급여·마감일이 바뀌면 마지막 값만 남습니다(`job_postings`는 덮어씀).
- **직종 분류**: 제목 키워드 규칙(`pipeline/sources.py`)이라 규칙을 바꾸면 과거 공고의 직종도 다음 수집 때 바뀝니다(진행 중 공고만). 규칙을 바꾼 날은 위 표에 적습니다.
- **API 자체 변경**: 출처가 응답 항목·필터를 바꾸면 수집 건수가 갑자기 달라질 수 있습니다. `ingest_runs.fetched_count`가 전날의 절반 미만이면 그날은 반영하지 않습니다.
