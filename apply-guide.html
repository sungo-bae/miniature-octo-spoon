지원하기, 이렇게 따라하세요

"지원하기" 버튼을 눌렀는데 낯선 화면이 나와서 당황하신 적 있으신가요? 실버잡 공고는 두 가지 방식으로 지원하게 되는데, 각각 차근차근 안내해 드립니다. 혼자 하기 어려우시면 언제든 아래 카카오톡으로 문의해 주세요.

먼저, 공고 카드에 붙은 표시를 확인하세요

"공공데이터" 표시가 있으면 → 고용24(옛 워크넷) 사이트를 통해 지원합니다 (1번 참고)

"지역업체 등록" 표시가 있으면 → 전화나 카카오톡으로 직접 문의합니다 (2번 참고)

1. "공공데이터" 공고에 지원하는 방법 (고용24)

실버잡의 "지원하기" 버튼을 누르면, 정부가 운영하는 고용24(work24.go.kr) 사이트의 해당 공고 화면으로 이동합니다. 화면 구성은 시기에 따라 조금씩 달라질 수 있지만, 순서는 대체로 같습니다.

1. 실버잡에서 공고를 누르고, 내용을 확인한 뒤 "지원하기" 버튼을 누릅니다. 고용24 사이트로 화면이 바뀝니다.

2. 고용24에 처음 오셨다면 회원가입(간편인증)이 필요합니다. 휴대폰 본인인증으로 비교적 간단하게 가입할 수 있습니다.

3. 로그인 후, "마이페이지"에서 이력서를 미리 등록해두면 지원이 훨씬 수월합니다. (이력서 쓰는 법은 구직 꿀팁 페이지의 기본 양식을 참고하세요)

4. 다시 공고 화면으로 돌아와 "지원하기" 버튼을 누르고, 등록해둔 이력서를 선택해 제출합니다.

5. 제출한 내용은 "지원 내역 조회" 메뉴에서 언제든 다시 확인할 수 있습니다.

화면이 낯설거나 중간에 막히시면 걱정하지 마시고, 공고에 적힌 담당자 연락처로 직접 전화해서 "실버잡 보고 지원하려는데 어떻게 하면 되나요?"라고 물어보셔도 됩니다. 대부분 친절하게 안내해 드립니다.

2. "지역업체 등록" 공고에 지원하는 방법

이 공고들은 실버잡에 업체가 직접 등록한 것으로, 별도 사이트로 이동하지 않습니다. 공고 상세 화면에 나와 있는 문의처(담당자 이름·전화번호)로 직접 연락하시면 됩니다.

1. 공고 상세 화면에서 "문의처"에 적힌 전화번호를 확인합니다.

2. 전화를 걸어 "실버잡 보고 연락드렸습니다"라고 말씀하시고, 공고 제목을 함께 알려주시면 됩니다.

3. 통화가 어려우시면, 공고 화면의 "지원하기" 버튼을 눌러 실버잡 카카오톡 채널로 문의하실 수도 있습니다.

3. 그래도 막히신다면

혼자 하시기 어려운 부분이 있으면 언제든 편하게 문의해 주세요. 운영자가 직접 확인하고 답변드립니다. 다만 실버잡은 1인이 운영하는 서비스라, 지원서를 대신 제출해드리는 것까지는 어려울 수 있는 점 양해 부탁드립니다 — 대신 어느 단계에서 막히셨는지 알려주시면 그 부분을 더 쉽게 풀어서 안내해 드리겠습니다.
